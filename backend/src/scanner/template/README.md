# Goldtech Network Behavior Scanner

Este é o módulo de Diagnóstico de Segurança para a coleta e análise de comportamento de rede e processos locais.

## Como Executar

1. Extraia o conteúdo deste arquivo ZIP em um diretório local (ex: `C:\GoldtechScanner`).
2. Clique com o botão direito em `Executar-Diagnostico.bat` e selecione **Executar como Administrador**.
3. Aguarde a conclusão da varredura.
4. O resultado será gerado em formato JSON na mesma pasta, contendo os detalhes coletados.
5. Envie o relatório gerado de volta para o analista da Goldtech.
