# Checklist Operacional do Técnico

Este checklist serve de orientação para a execução do diagnóstico de segurança em computadores de clientes.

- [ ] Verificar privilégios de Administrador na máquina alvo.
- [ ] Descompactar o pacote em diretório sem restrições de escrita.
- [ ] Executar o script `Executar-Diagnostico.bat`.
- [ ] Aguardar até a finalização do escaneamento sem fechar a janela.
- [ ] Confirmar a criação do arquivo de resultados (ex: `resultado-diagnostico.json`).
- [ ] Salvar o arquivo de resultados em local seguro para análise posterior.
